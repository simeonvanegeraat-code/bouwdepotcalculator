# Voor en na: de header die de rekentools vindbaar maakt

**Datum:** 30-09-2026 · [spec/header.md](../spec/header.md)

Alles hieronder is gemeten in de browser op `bouwdepot-obvion.html` en
`nieuwbouw.html`, niet geschat.

## De kern

| Op 375px breed | Voor | Na |
|---|---:|---:|
| **Bereikbare links vanuit de kop** | **1** | **13** |
| Bereikbare rekentools | 0 | 11 |
| Zichtbaar in de kop | "Uitleg" | "Rekenhulpen" |

Onder 760px stonden alle links op één na op `display: none`, zonder
vervanging. De `bs-staafjes` ernaast leek een menuknop maar was een decoratief
merkteken met `aria-hidden="true"`; het commentaar in de CSS noemde het wel de
menuknop, maar hij was nooit aangesloten. Nu zit dat merkteken ín de knop, dus
de oorspronkelijke bedoeling klopt alsnog.

## Gedrag

Gemeten, niet aangenomen:

| Toets | Uitkomst |
|---|---|
| Paneel open op 1440px | bovenkant exact 72px, volle breedte, 0 elementen buiten beeld |
| Escape | sluit het paneel |
| Focus na sluiten | terug op `.bs-kop__knop` |
| Zichtbare groepen op desktop | 5 van 6 (de mobiele groep is verborgen) |
| Aanraakzones desktop | knop 44px, kleinste link 56px |
| Aanraakzones mobiel | kleinste 44px |
| Horizontaal scrollen | nergens, op geen van beide breedtes |
| Paneel scrollt op 375px | 1038px inhoud in 738px, laatste link bereikbaar |

Dat Escape werkt en de focus terugkeert is geen eigen code: dat doet de Popover
API. Er staat **geen enkele regel JavaScript** achter deze header.

## Zonder popover-ondersteuning

De 7,5% die het niet heeft. Uit de CSSOM gelezen:

| | zonder ondersteuning | met ondersteuning |
|---|---|---|
| `.bs-kop__knop` | `none` | `inline-flex` |
| `.bs-kop__terugval` | `inline-flex` | `none` |
| `.bs-paneel` | `none` | opent bij `:popover-open` |

De standaardtoestand is dus de werkende link, en het paneel is de verbetering
die er pas bovenop komt als de browser aantoonbaar meedoet. Andersom — de
verbetering als uitgangspunt — was precies de fout die hier zat.

## Wat open blijft

De terugvallink wijst naar `/#gereedschap` op de homepage. Die sectie heet daar
nog "Zeven rekenhulpen" terwijl het er inmiddels elf zijn. Kleine
inconsistentie, valt buiten dit werk.
