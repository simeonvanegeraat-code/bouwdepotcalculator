# Context

Achtergrond die niet uit de code te lezen is: hoe de techniek in elkaar zit,
waar de juridische grens ligt, en waarom eerdere keuzes zijn gemaakt.

| Bestand | Waarvoor |
|---|---|
| [techniek.md](techniek.md) | Stack, datastroom, wat gegenereerd is en wat handwerk |
| [JURIDISCHE-CHECK.md](JURIDISCHE-CHECK.md) | De AFM-grens. **Lees dit vóór je iets bouwt dat op een aanbeveling lijkt** |
| [componenten.md](componenten.md) | De componenten van de huidige site, en waar ze bewust niet voor zijn |
| [beslissingen.md](beslissingen.md) | Genomen besluiten met hun reden, nieuwste bovenaan |

## Wat hier niet meer staat

Op 9 oktober 2026 is de productrichting vervangen door de acht kerndocumenten
in de repo-root. Drie bestanden uit deze map zijn daarmee naslag geworden en
verhuisd naar [../archief/context/](../archief/context/):

- `bedrijf.md` — product, bezoeker en verdienmodel. Vervangen door
  [../PRODUCT_VISION.md](../PRODUCT_VISION.md).
- `ontwerpreferenties.md` — wat "betrouwbaar" betekende voor de
  broadsheet-richting. Vervangen door [../DESIGN_SYSTEM.md](../DESIGN_SYSTEM.md).
- `concurrentie-verbouwbegroting.md` — concurrentieonderzoek bij een afgeronde
  spec.

`componenten.md` beschrijft de **huidige** site en blijft nodig zolang die
draait. Het is geen ontwerpvoorschrift voor het nieuwe werk; daarvoor geldt
`DESIGN_SYSTEM.md`.
