# Routines

Terugkerende taken met een vast stappenplan, zodat ze elke keer hetzelfde gaan
en niemand hoeft te onthouden hoe het ook alweer moest.

| Routine | Wanneer |
|---|---|
| [bronnen-controleren.md](bronnen-controleren.md) | Elke maandag, na de melding van de workflow |
| [nieuwe-pagina.md](nieuwe-pagina.md) | Bij elke nieuwe pagina |
| [publiceren.md](publiceren.md) | Voor elke deploy |
| [search-console.md](search-console.md) | Wekelijks, zodra er een export is |

Een routine hoort kort te zijn. Wordt hij lang, dan is het waarschijnlijk een
spec.
